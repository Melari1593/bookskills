# Grafo de conocimiento — Fungal Machines (2023)

Grafo estructural del libro de Andrew Adamatzky (ed.). Incluye 5 partes, 26 capítulos, conceptos y taxones. Relaciones `CONTIENE`, `ESTUDIA`, `ESTUDIA_TAXON`. No se infieren causalidades.

## Archivos
- `graph.json`: nodos y aristas de la estructura del libro.
- `nodes.csv`, `edges.csv`: importación a Gephi/Neo4j.

## Consultas sugeridas
- Comparar registros eléctricos de Pleurotus y Ganoderma.
- Explorar sensores y dispositivos miceliales.
- Relacionar autómatas, compuertas y circuitos.

**Precaución:** las hipótesis de cognición y lenguaje no demuestran capacidades equivalentes a las humanas.

**Nota:** esta versión publicada es el grafo estructural; el archivo local original contiene además extractos de resúmenes de capítulos.
