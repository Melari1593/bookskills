# Image to Web Design System

Skill universal para transformar referencias visuales en sistemas de diseño web y componentes originales.

## Uso
Adjunta una imagen y solicita: `$image-to-web-design-system Analiza esta referencia y crea una web responsive en React.`

## Salidas
Análisis visual, tokens de diseño, componentes React/TypeScript, ilustraciones SVG originales, efectos CSS y demo responsive.

## Estilos compatibles
Minimalista, editorial, botánico, chinoiserie, neumorfismo, bajorrelieve, brutalista, 3D, fotografía y otros. No impone ningún estilo por defecto.

## Archivos
- `SKILL.md`: flujo y reglas
- `references/analysis-template.md`: plantilla de análisis
- `references/relief-recipes.md`: técnicas CSS/SVG
- `schemas/design-tokens.schema.json`: esquema de tokens

La skill es una guía para agentes de desarrollo; no es por sí sola un conversor automático ejecutable.
