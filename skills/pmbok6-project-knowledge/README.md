# Skill PMBOK 6 — Grafo de conocimiento

Skill portátil basada en la extracción estructural inicial del PMBOK 6 (2017).

## Uso
Lee `SKILL.md`. Una vez importados los archivos `data/` del paquete ZIP, ejecuta `python scripts/query_graph.py stats` o `python scripts/query_graph.py area 11`.

**Estado de esta publicación:** documentación y motor de consultas; los datos del grafo deben incorporarse desde el ZIP generado por separado. No se incluye el libro original.
