## Composición

Una lámina vertical puede reservar 40–55 % para el espécimen, 25–35 % para ampliaciones y el resto para contexto y fuentes. Una secuencia usa flechas solo para orden causal. Mantener cada tejido o fase con color consistente. En móvil, preferir 4–7 tarjetas a una lámina saturada. Las imágenes de referencia orientan la dirección editorial; no son activos ni fuentes científicas.
