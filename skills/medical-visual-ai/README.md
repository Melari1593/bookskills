# Medical Visual AI

Skill para convertir documentos médicos en ilustraciones científicas y material educativo mediante prompts para Nano Banana.

## Uso
Adjunta un documento e indica especialidad, audiencia, formato y cantidad de piezas. Ejecuta `SKILL.md` para obtener catálogo y prompts individuales.

## Seguridad
La skill no conecta automáticamente con Nano Banana ni garantiza la exactitud de imágenes generadas. Revisar contenido clínico antes de publicar.

## Paquete ampliado
El proyecto completo con prompts, esquemas, flujos y ejemplos se distribuye también como `medical-visual-ai.zip`.
